# 世界模型：定义、澄清、区别与边界

[AGI 人本拟合论](https://github.com/yuyuguilab/practice-fitting-theory)系列第六篇。把该理论的概念工具延伸到“世界模型”一词：

- **定义**——功能概念而非实体概念：两条件（行动条件性 C1、组件可调用性 C2）；三系实现（写入、学出、先学后写）。
- **澄清**——位置多态：同一功能概念落在四个位置上（组件/评测基准/状态表征/模拟环境），四种调用形态（展开/评分/查询/训练场与生成）；命名竞争谱系与适存条款。
- **分析**——三个论断（位置、概率、任务）与一条界限（递归自改进须保留真实数据掺配；校准不能自证）。
- **区别**——与智能（策略对模型）、与通用人工智能（判准错位、组件进步不可转账）；“智能世界模型”终局概念的结构分析（四路合流、四要件、三道边界）。
- 八条证伪条款与面向新案例的准入协议。
